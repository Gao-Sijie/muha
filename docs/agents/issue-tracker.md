# SDK issue tracker

Use GitHub Issues for `Gao-Sijie/muha` through the `gh` CLI. Always pass
`--repo Gao-Sijie/muha` when reading, commenting or closing SDK tickets so an
adjacent private checkout cannot select the wrong repository.

Fetch the ticket with comments before implementation. Follow its dependencies
and authorization gates; `ready-for-agent` is not external-operation authority.
Record commands, exit codes, revision, environment and exceptions in durable
sanitized evidence. Close only completed tickets. Preserve an originating spec's
body/state when its tickets explicitly require it.
