# Accept Only Ordered Text and Image Turn Input

`TurnInput` is a non-empty readonly tuple of `TurnContentPart`, whose closed union is non-empty `{ type: "text"; text: string }` or `{ type: "image"; source: { type: "file"; path: string } | { type: "base64"; mediaType: ImageMediaType; data: string } }`; `ImageMediaType` is exactly `"image/png" | "image/jpeg" | "image/webp" | "image/gif"`. Part order is preserved and an image-only Turn is valid. File paths are absolute and Core reads and verifies a supported image before native acceptance; base64 is non-empty raw base64 rather than a data URL, decodes successfully, and matches its declared media type. Muha V0.1 accepts no remote URL, relative file path, SVG, audio, video, or arbitrary content part. Core validation and file-read failures reject with `INVALID_INPUT`, while a Harness or model image rejection is `HARNESS_ERROR`. This sharpens ADR-0029's text-and-image boundary.
