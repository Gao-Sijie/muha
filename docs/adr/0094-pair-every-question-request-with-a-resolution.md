# Pair Every Question Request With a Resolution

`TurnHandle` adds `respondToQuestion(requestId, response): Promise<void>`. `question.requested` carries one `QuestionRequest`; `question.resolved` identifies its Core request ID and carries exactly one resolution: answered with the authoritative answers and source caller or Harness, dismissed with source caller or Harness, or invalidated with source Harness or Turn. The response command succeeds only after the native Harness accepts it and Core durably records and queues the resolution event. Native resolution can win a race with the caller, and every pending Question is invalidated before the Turn's terminal event. Every requested Question receives exactly one public resolution, matching the lifecycle invariant already used for Approval Requests. This supersedes ADR-0074 only where that ADR called its former method list complete; its iterator, result, interruption, Approval, and single-consumer rules remain unchanged.
