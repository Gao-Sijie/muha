# Close Runtime irreversibly after bounded shutdown

Calling `MuhaRuntime.close()` irreversibly moves the Runtime from active through closing to closed, concurrently interrupts every active Turn, closes every Session Handle without deleting native conversations, and starts each Adapter's configured shutdown bound without waiting for callers to drain queued Turn Events. An expired Adapter bound escalates to forced reclamation of its complete Muha-owned process tree rather than itself causing failure; successful reclamation is successful closure, while failed reclamation is reported only after Core has attempted every Adapter and closed its Diagnostic Event Store and guards. Every accepted Turn receives an interrupted terminal value, existing Turn Handles may drain their already queued events, and the Runtime remains closed and rejects all future commands even when `close()` rejects because cleanup did not fully succeed.
