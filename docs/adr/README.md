# SDK decisions

[CONTEXT.md](../../CONTEXT.md) defines domain vocabulary. Numbered ADRs preserve
historical decisions; a historical transport or delivery rule is not necessarily
the current behavior. [ADR-0140](0140-admit-harnesses-by-muha-contract-conformance.md)
defines Performance-first; [ADR-0141](0141-separate-sdk-development-source-from-private-orchestration.md)
defines the SDK's independent repository boundary.

Historical links to excluded internal plans/diagnostics point to the
[private-history explanation](../testing/private-history.md). Only those link
destinations/presentation changed; the numbered decisions remain historical.
