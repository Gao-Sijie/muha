# Scope public events to Turns

The Turn Handle is Muha V0.1's only public event boundary, so its closed `TurnEvent` union contains `turn.started`; assistant message start, text delta, reasoning delta, and completion; tool start, update, and completion; approval request and resolution; cumulative usage updates; and exactly one final `turn.completed`, `turn.failed`, or `turn.interrupted` event. Session and Runtime lifecycle events, native inner-loop events, file watching, subagents, compaction, logs, connection state, and `adapter.raw` are excluded; Session operations instead report through their method results and `AgentSession.state`, while every native event is retained privately as a complete Native Event Record. Text deltas represent native chunks or losslessly coalesced adjacent chunks rather than individual tokens, completed events carry authoritative complete values, and optional event kinds such as reasoning and usage may be absent without implying that the Harness lacks the underlying behavior. ADR-0090 supersedes only the former exclusion of generic questions by adding the structured `question.requested` and `question.resolved` Turn events.
