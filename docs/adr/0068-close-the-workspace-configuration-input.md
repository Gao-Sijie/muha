# Close the Workspace Configuration Input

`ConfigureWorkspaceOptions` contains exactly `workspacePath: string`, `createIfMissing?: boolean`, `harnesses?: readonly [HarnessKind, ...HarnessKind[]]`, `skills?: readonly SkillSource[]`, and `mcpServers?: readonly McpServerConfig[]` in V0.1. Core requires and normalizes an absolute Workspace path, defaults directory creation to true, and defaults omitted target Harnesses to every enabled Harness in Runtime registration order; explicit targets are non-empty, unique, and enabled in the current Runtime. Skill and MCP arrays may be omitted or empty, so the operation may only validate or create the directory. Workspace configuration accepts no Approval Policy, Session value, native option, or unknown field and guarantees only that its filesystem attempts have settled, not that an active Harness has reloaded them.
