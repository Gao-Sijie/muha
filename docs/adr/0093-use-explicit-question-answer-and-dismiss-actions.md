# Use Explicit Question Answer and Dismiss Actions

Status: superseded by ADR-0139 for the public Question answer union; one answer per field and whole-request dismissal remain in force.

`QuestionResponse` is exactly `{ action: "answer"; answers: readonly [QuestionAnswer, ...QuestionAnswer[]] } | { action: "dismiss" }`. `QuestionAnswer` is the closed union `{ questionId; kind: "options"; optionIds: readonly [string, ...string[]] }`, `{ questionId; kind: "custom"; text: string }`, `{ questionId; kind: "optionsWithCustom"; optionIds: readonly [string, ...string[]]; text: string }`, and `{ questionId; kind: "skipped" }`. An answer action contains exactly one entry for every requested Question with no duplicate or foreign Question/option IDs, regardless of input order; option IDs are unique within an answer, a non-multiple Question accepts exactly one selected option, custom text is non-empty and requires `allowCustom`, and options-with-custom additionally requires `multiple`. Skipped omits one answer while dismiss rejects the complete request. This maps losslessly to Kimi's five answer forms and whole-request dismiss and to OpenCode's per-question string arrays and whole-request reject.
