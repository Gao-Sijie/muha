# Release the Complete First Scope as V0.1

Muha's first declared release is the single V0.1 milestone, represented by SemVer `0.1.0` for `@muha-sdk/core` and the Codex, OpenCode, and Kimi Adapter packages. The project does not define separate product-level alpha/beta stages, a stable Core paired with experimental official Adapters, or staggered first releases. V0.1 is declared only after the complete first-release scope and acceptance suite are finished, then all four official packages are published together at the same version. Internal development builds and CI artifacts do not constitute a declared Muha release.
