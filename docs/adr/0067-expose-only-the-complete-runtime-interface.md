# Expose Only the Complete Runtime Interface

`MuhaRuntime` exposes read-only `runtimeId: string`, normalized absolute `dataDir: string`, `enabledHarnesses: readonly HarnessKind[]` in Registration order, and synchronous `status: "active" | "closing" | "closed"`, plus exactly the asynchronous methods `configureWorkspace(options)`, `createSession(options)`, `resumeSession(options)`, `listSessions(options)`, and idempotent `close()`. It has no public constructor, separate `init`, Adapter getter, Runtime event stream, global accessor, dynamic Harness registration, or other V0.1 method; callers obtain an immediately usable instance only through `await createMuhaRuntime(config)`. ADR-0098 subsequently adds the read-only, non-rejecting `termination` Promise without adding a Runtime event stream or method.
