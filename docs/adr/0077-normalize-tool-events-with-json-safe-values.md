# Normalize Tool Events with JSON-Safe Values

Tool events are `tool.started` with Core-generated per-Turn `toolCallId`, non-empty `toolName`, and complete `input: JsonValue`; zero or more `tool.updated` with the ID and `update: JsonValue`; and exactly one `tool.completed` with the ID, `output: JsonValue`, and `isError: boolean`. `JsonValue` is recursive JSON null, boolean, finite number, string, readonly array, or string-keyed readonly object and excludes undefined, BigInt, functions, non-finite numbers, and cycles. Adapters wait for parseable complete input before start, use null for absent output, and translate business values rather than exposing native envelopes. Tool failure does not itself fail the Turn, concurrent tool lifecycles may interleave under Core sequence order, and an update/completion without start or a duplicate completion is an `ADAPTER_PROTOCOL_ERROR` Turn Failure.
