# Make Turn Handles the event boundary

`AgentSession.startTurn(input)` will return a Turn Handle whose one-shot, single-consumer `AsyncIterable` event stream is the authoritative interface for observing and controlling that Turn, rather than splitting correctness across a prompt result and session-level subscriptions. The first iterator claims the stream and a second claim fails. The handle exposes its `turnId`, unique `result` promise, interaction responses, and `interrupt()`; it has no subscription, replay, multicast, or close API, and any future convenience APIs must be implemented over this boundary. ADR-0074 supersedes the former early-iterator-exit rule: leaving iteration early neither interrupts nor drains the Turn. ADR-0094 adds the Question response operation alongside Approval response.
