# Fail OpenCode Turns Closed on SSE Disconnection

Before accepting an OpenCode Turn, the Adapter ensures that the Workspace's authenticated SSE stream is connected and has delivered its native connected signal. Because the native stream has no replay cursor or lossless resumption contract, an unexpected disconnect while Turns are active invalidates their pending Approvals, makes a best-effort native abort request, fails each affected Turn with `ADAPTER_PROTOCOL_ERROR`, and closes its Agent Session handle without deleting the native Session; callers may explicitly resume that Session afterward. Muha does not reconstruct or synthesize possibly missed Turn Events from later message snapshots. A disconnect with no active Turn emits no public event and is reconnected before the next workspace operation is accepted.
