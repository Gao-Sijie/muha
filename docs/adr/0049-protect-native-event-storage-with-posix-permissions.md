# Protect Native Event storage with POSIX permissions

On supported Linux filesystems, Muha requests mode `0700` for every directory it creates under the default `~/.muha/<runtimeId>` path and mode `0600` for Diagnostic Event Store database, WAL, shared-memory, and lease files, allowing the process umask only to remove further permissions. Muha does not change an existing caller-managed directory's mode, but refuses Event Store initialization when an existing sensitive Muha file grants any group or other-user permission rather than silently changing it; these owner-mode protections are not encryption, do not isolate processes running as the same user or root, and are not guaranteed for WSL-mounted Windows or other filesystems that do not faithfully implement POSIX mode bits.
