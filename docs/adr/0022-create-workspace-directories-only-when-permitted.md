# Create Workspace directories only when permitted

`configureWorkspace` permits Muha to create a missing directory by default, while direct Agent Session creation requires an existing directory and never creates or configures it implicitly. Session resumption denies directory creation by default; a caller may opt into creation during resumption only to recreate the exact `workspacePath` already bound to that Session and cannot supply a replacement path. Resumption checks only directory existence and never accepts or validates Skills or MCP configuration, so a recreated empty directory is passed to the Harness as-is. Directory creation grants no ownership: Muha never deletes the directory, and existing directories remain untouched except for explicitly requested Skills and MCP configuration.
