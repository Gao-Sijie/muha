# Record Pi SDK semantic callbacks and data results

For the Pi-only SDK integration, ADR-0107's inbound semantic boundary includes complete JSON-safe `AgentSession.subscribe` events, `bindExtensions.onError` callbacks, native `SessionManager.list` results, and the `createAgentSession` model-fallback warning and extension-load errors, each tagged with its actual SDK source before the host's sole Diagnostic Event Store commits it and any public normalization occurs. SDK objects/functions, model/auth runtimes, transport headers, process logs, outbound commands, readiness checks and Adapter-generated IPC acknowledgements are not native evidence; capturing entire SDK object graphs would include credentials and runtime implementation state rather than semantic results. This adds neither a child Runtime/store nor a public replay interface, and native event content remains sensitive and unredacted under ADR-0013.
