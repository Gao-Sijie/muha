# Delegate Skill Source Syntax to the Skills CLI

`SkillSource` is exactly `{ source: string; skillNames?: readonly [string, ...string[]] }`. `source` is one non-empty positional source accepted by the pinned `skills add <source>` CLI and Muha passes it as one argument without a shell, inventing no separate repository, URL, revision, or provider schema and exposing none of the CLI's internal types; the CLI runs with `workspacePath` as its working directory, so relative local sources resolve from that Workspace rather than `process.cwd()`. Omitted `skillNames` maps to all discovered Skills, while an explicit list is non-empty and unique. For every selected Harness, Muha invokes only non-interactive project-scoped copy installation with telemetry disabled; sources execute in caller order, later successful same-name installations replace earlier content, unrelated existing Skills remain, and one failure does not stop independent Harness or source attempts. Muha exposes no global, symlink, removal, update, synchronization, or arbitrary CLI option.
