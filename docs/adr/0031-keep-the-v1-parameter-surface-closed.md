# Keep the V0.1 parameter surface closed

Muha V0.1 exposes only parameters that its public contract names and types explicitly; it provides no `harnessOptions`, `nativeOptions`, `extraArgs`, index signature, or arbitrary parameter map at Runtime, Workspace configuration, Session, or Turn boundaries. Official Harness Registrations accept only their enumerated process-level options, while `model` remains the explicitly supported Harness-native Session value described in ADR-0030; `reasoningEffort` and every other upstream option not separately accepted by Muha are unsupported in V0.1. Adding such an option later requires an explicit Muha Capability and public type rather than passthrough, trading immediate access to vendor features for a stable SDK contract and deliberate failure semantics.
