# Deliver V0.1.1 as a Follow-up Local Artifact Set

ADR-0111 originally described Muha V0.1 as a single `0.1.0` lockstep release of Core and the Codex, OpenCode, and Kimi Adapters, delivered as four checksummed local npm tarballs. V0.1.1 supersedes only that single-release description: a patch release is now allowed within the same local delivery model, and it is delivered as a second lockstep artifact set at `0.1.1`. This does not relax the local-only, package-private, exact-dependency, four-package lockstep, or SHA-256 checksum constraints from ADR-0111, and no V0.1.1 artifact is published to the npm Registry or GitHub Releases. Adapters still declare an exact `@muha-sdk/core` dependency at the same version so that mixed local artifact sets fail during installation rather than at runtime, and the historical `0.1.0` artifact set and its qualification record remain audit evidence.
