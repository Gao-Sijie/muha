# Encode OpenCode Model Pairs as Native Model Strings

For the OpenCode Harness, Muha represents the native `{ providerID, modelID }` pair as the Harness Model string `<providerID>/<modelID>`, splitting caller input at the first slash and preserving the remainder as `modelID`. Both components must be non-empty and the complete string must have no leading or trailing whitespace; Muha does not trim, change case, alias, normalize, or reinterpret either value. Invalid syntax is `INVALID_INPUT`, while a well-formed pair rejected by OpenCode's native model catalog is `HARNESS_ERROR`. The Adapter sends the two fields required by the OpenCode HTTP wire schema and joins native fields back into the same string, so this is a lossless public encoding of OpenCode identity rather than a claim that every native endpoint accepts one combined string.
