# Support Only Portable MCP Server Configurations

`McpServerConfig` is a closed union of `{ name: string; transport: "stdio"; command: string; args?: readonly string[]; env?: Readonly<Record<string, string>> }` and `{ name: string; transport: "http"; url: string; headers?: Readonly<Record<string, string>> }`. Names and stdio commands are non-empty, argument boundaries are preserved without a shell, and remote URLs are absolute HTTP or HTTPS URLs; environment values and headers are written verbatim without resolving placeholders or managing secrets. Muha V0.1 exposes no legacy SSE transport, timeout, OAuth scopes, enabled flag, tool filter, arbitrary native fields, or `add-mcp` types. Entries apply in input order and a later successful same-name entry replaces earlier content while preserving unrelated native servers; Codex and OpenCode use the pinned `add-mcp` programmatic API behind Muha guards, Kimi uses a Muha-maintained equivalent project writer, and every entry/target attempt settles independently without rollback.
