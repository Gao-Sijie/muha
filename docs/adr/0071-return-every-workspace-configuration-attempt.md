# Return Every Workspace Configuration Attempt

`ConfigureWorkspaceResult` is exactly `{ workspacePath: string; created: boolean; attempts: readonly WorkspaceConfigurationAttempt[] }`. Invalid path input, a missing directory when creation is disabled, or directory preparation failure rejects the command before configuration, while every selected-Harness × Skill-source and selected-Harness × MCP-server operation that follows produces one discriminated succeeded or failed attempt; failed Skill attempts carry only `SKILL_CONFIGURATION_FAILED`, failed MCP attempts carry only `MCP_CONFIGURATION_FAILED`, and each attempt identifies its `kind`, `harness`, and zero-based `inputIndex` without echoing source, env, headers, or other caller configuration. Attempts follow target-Harness order and, within each Harness, Skill input order followed by MCP input order; an empty configuration produces an empty list. `created` means only that this call created the Workspace directory, and a failed attempt may have left partial native writes because Muha neither rolls back nor claims atomic vendor configuration.
