# Resolve Every Accepted Turn with Its Terminal Event Payload

The final event is exactly one of `turn.completed` with authoritative final `AssistantMessage` and optional final usage, `turn.failed` with optional usage and a `TurnFailure` restricted to `HARNESS_ERROR`, `ADAPTER_PROTOCOL_ERROR`, `EVENT_STORE_ERROR`, `TURN_EVENT_BACKPRESSURE`, or `TURN_EVENT_TOO_LARGE`, or `turn.interrupted` with optional usage and reason `"caller" | "sessionClosed" | "runtimeClosed" | "harness"`. `TurnResult` is the same three-way union using `status` and `turnId`, always resolves, and exactly matches the terminal event payload. Backpressure, oversize, store, Harness, and protocol failures are failed rather than interrupted; closure interrupts, and un-attributable native cancellation uses Harness. An interrupt/completion race accepts the first legal terminal state, so an interrupt command cannot guarantee interruption. Terminal values contain no event list, Tool history, reasoning, or transcript. This sharpens ADR-0033.
