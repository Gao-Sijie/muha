# Model Assistant Output as Start, Delta, and Completion

The first five public events are payload-free `turn.started`; `assistant.message.started` with Core-generated per-Turn `messageId`; `assistant.message.delta` and `assistant.reasoning.delta` with that ID and a non-empty native or losslessly coalesced `delta`; and `assistant.message.completed` with authoritative `{ id: messageId; text: string }`. Started precedes every delta and completion for its message. Reasoning has no separate start or completion and never contributes to final message text; a Harness may omit deltas and emit only message start/completion, and one Turn may contain multiple messages. The last completed Assistant Message is a successful Turn's final message, while native success without any completed Assistant Message becomes an `ADAPTER_PROTOCOL_ERROR` Turn Failure. `turn.started` does not echo input.
