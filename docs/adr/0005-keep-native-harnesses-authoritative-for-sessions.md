# Keep native Harnesses authoritative for sessions

Each Coding Harness will remain the authoritative owner and store of its Agent Sessions; Muha will normalize listing and resumption without maintaining a Session Index or shadow session database. Listing delegates to one enabled Harness, is scoped by a caller-supplied normalized `workspacePath`, and returns every native Session the Harness reports there rather than only Sessions created through Muha, so Muha exposes neither provenance filtering nor global enumeration across unknown directories. Each Listed Session is a point-in-time JSON-safe value containing its Session Reference plus optional native title and timestamps, while the Reference itself carries only the stable Harness Kind, native session identity, and bound `workspacePath`; resumption accepts that Reference rather than a replacement path and cannot recover a Session the native Harness no longer resolves. Native Event Records begin only when Muha observes a Session, and Core's active-Turn guard cannot constrain native clients outside the current Runtime.
