# Treat Session Model as a Next-Turn Selection

`AgentSession.model` is the Harness-native model identifier currently selected by that Muha handle for subsequent Turns, and idle-only `setModel(model)` validates the selection through the native Harness before updating the handle without requiring an immediate native Session mutation. For OpenCode, the Adapter validates the provider/model against the server's native catalog, retains the selection in the handle, and supplies it on the next `startTurn`; OpenCode persists it as the Session's current model only when that Turn is accepted. Closing a handle before such a Turn need not persist the selection natively, and Muha never persists it itself, so callers requiring deterministic resumption pass `model` again. This refines ADR-0030 and ADR-0072: “native success” for `setModel` means successful native validation and selection for future Turn submission, not that every Harness exposes a standalone Session-model mutation.
