# Close the Runtime Configuration Surface

`MuhaRuntimeConfig` contains exactly `harnesses: readonly [HarnessRegistration, ...HarnessRegistration[]]`, `dataDir?: string`, `maxQueuedEventsPerTurn?: number`, and `maxQueuedEventBytesPerTurn?: number` in V0.1. Registrations are non-empty, unique by Harness Kind, and therefore limited to the three official kinds; Adapter options are fixed when each Registration is created and cannot be overridden by Runtime configuration. An explicit `dataDir` is absolute, while omission uses `<os.homedir()>/.muha/<runtimeId>`; Core generates the Runtime ID and callers cannot configure it. The event-count and serialized UTF-8 byte limits accept positive safe integers and default respectively to 4,096 and 16 MiB. Unknown fields and duplicate Registrations are `INVALID_INPUT`.
