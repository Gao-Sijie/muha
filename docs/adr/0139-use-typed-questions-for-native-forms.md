# Use Typed Questions for Native Forms

Muha's public Question is a closed, harness-neutral union of select, multiselect, text, number, boolean, and external-acknowledgement fields, with typed answers, defaults, constraints, and earlier-field conditions. This supersedes the option/free-text-only field and answer shapes in ADR-0092 and ADR-0093: a separate Form lifecycle would duplicate the blocking Question contract, while an untyped native payload would shift compatibility and validation onto consumers. Core owns public IDs and response validation; Adapters retain native keys, option values, and hidden defaults privately until the request settles. The source-breaking adjustment is intentional before the first public release, without a legacy Question output format.

Hidden native Form defaults and comparisons against them cannot be recorded as ordinary public or diagnostic data. As a specific exception to ADR-0013's complete Native Event Record rule, the OpenCode v2 Adapter redacts hidden defaults, dependent comparisons, reply answers, and arbitrary Form metadata in persisted events while passing the unredacted event privately to its live Turn mapper. This sacrifices diagnostic payload completeness for those fields to avoid persisting credential-like material. Hidden remains a presentation hint, not an automatic permission or answer; `useDefault` resolves the private native value only when the caller selects it.
