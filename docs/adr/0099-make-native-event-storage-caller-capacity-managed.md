# Make Native Event Storage Caller-Capacity-Managed

Muha V0.1 retains every complete unredacted Native Event Record and every required Core Event Record and therefore does not prune, rotate, overwrite, compact away, cap, or expose a deletion/retention API for the SQLite Diagnostic Event Store. The in-memory Turn queue limits do not bound persistent storage. Callers use the public Runtime `dataDir` to monitor filesystem capacity and may archive or delete a Runtime directory only after that Runtime is completely closed; Muha never automatically removes active or historical Runtime directories, and externally deleting active storage is unsupported. Disk exhaustion or any loss of reliable SQLite write/commit capability follows ADR-0050 and fatally closes the Runtime. Documentation must warn that retained directories can grow without bound and contain sensitive unredacted native payloads protected only by the established filesystem permissions.
