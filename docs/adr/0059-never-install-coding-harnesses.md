# Never Install Coding Harnesses

Muha Core and every official Adapter neither install, download, update, nor repair a Coding Harness, and their required or optional package dependencies must not transitively install a Harness distribution; a pure protocol client dependency is permitted only when it carries no Harness executable. The caller installs and authenticates each Harness independently and provides the native environment in which it can be discovered. During all-or-nothing Runtime initialization, every configured Adapter must start its fixed native command and reach the Adapter's basic ready state within the startup bound; a missing, unexecutable, failed, or unready configured Harness is an initialization failure, causes rollback of all successfully initialized components, and never produces a degraded Runtime with fewer enabled Harnesses than requested.
