# Expose Only the Complete Agent Session Interface

`AgentSession` exposes read-only `reference: SessionReference`, `model: string | undefined`, and synchronous JSON-safe `status` discriminated as `{ status: "idle" }`, `{ status: "running"; turnId: string }`, or `{ status: "closed" }`, plus exactly `startTurn(input): Promise<TurnHandle>`, idle-only `setModel(model): Promise<void>`, and idempotent `close(): Promise<void>`. `startTurn` returns only after the native Harness accepts the Turn, so failure before a Handle is a rejected Command with `MuhaError`, while every accepted Turn thereafter resolves through the Handle's terminal value. Model state updates only after native success; closing interrupts an active Turn and invalidates this Muha handle without deleting the native Session. V0.1 exposes no Session event stream, messages, transcript, summary, Adapter, native handle, or other Session method.
