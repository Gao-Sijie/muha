# Drive OpenCode Through a Muha-Owned Loopback Server

The OpenCode Adapter starts the fixed PATH command `opencode serve --hostname 127.0.0.1 --port 0 --no-mdns`, parses the native ready line to discover the actual listening port, and becomes ready only after the native health endpoint reports a healthy server. It drives sessions and commands through a Muha-maintained minimal HTTP client and consumes native events from the OpenCode server's native SSE event endpoint; concrete HTTP paths are pinned and tested Adapter implementation details rather than Muha architecture or public API commitments. Each Adapter release implements one tested upstream protocol shape without runtime path probing or legacy fallback, and a mismatch is an Adapter protocol failure. The Adapter does not depend on `@opencode-ai/sdk` or connect to a caller-managed OpenCode server. The ready line and other child stdout/stderr remain control output used only for lifecycle management and are neither Native Events nor persisted or publicly exposed.
