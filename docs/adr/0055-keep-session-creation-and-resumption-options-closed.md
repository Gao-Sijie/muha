# Keep Session creation and resumption options closed

`MuhaRuntime.createSession` accepts exactly an enabled Harness Kind, an existing absolute `workspacePath`, and optional Harness-native `model` and `approvalPolicy`, creates no directory, and performs no Skill or MCP configuration. `MuhaRuntime.resumeSession` accepts exactly a Session Reference, optional `model` and `approvalPolicy`, and `createWorkspaceIfMissing` defaulting to false; it can only recreate the Reference's immutable path as an empty directory, accepts no replacement path or Skill/MCP input, and otherwise uses the Workspace's current contents. Omitted approval policy means interactive, omitted model delegates to native restored or default behavior, and neither operation accepts system prompts, reasoning effort, arbitrary Harness options, or extra fields.
