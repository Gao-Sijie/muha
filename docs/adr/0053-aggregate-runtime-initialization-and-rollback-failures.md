# Aggregate Runtime initialization and rollback failures

`createMuhaRuntime()` rejects one mechanical `MuhaError` carrying `RUNTIME_INITIALIZATION_FAILED`, a non-empty `initializationFailures` list restricted to `HARNESS_ERROR` with `initialize` operation or `EVENT_STORE_ERROR` with newly supported `open` operation, and a possibly empty `rollbackFailures` list restricted to typed Harness- and Event Store-close failures. Normal cancellation caused by another Adapter's failure is omitted, while a task that cannot settle within its own startup bound remains an initialization failure; Harness entries in both lists follow Runtime registration order and Event Store entries follow them regardless of concurrent completion order. This replaces the former single component field without adding another error code or JavaScript aggregation channel.
